# 2. 通用函数

**数据订阅函数**：包括对行情数据进行订阅/取消订阅、刷新和缓存等函数。
 **与客户端交互函数**：包括发生消息到TQ策略管理器界面、发生信号到客户端个股界面、发送预警到客户端TQ策略信号等。
 **数据信息文件包**：我们提供各类特定的数据信息文件包。具体见download_file。
