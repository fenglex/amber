# 6.3 清空自定义板块成份股clear_sector

### 清空指定通达信客户端自定义板块的成份股

```
clear_sector(block_code:str = ''):
```

### 输入参数

| 参数 | 是否必选 | 参数类型 | 参数说明 |
| --- | --- | --- | --- |
| block_code | Y | str | 自定义板块简称 |

### 接口使用

```
from tqcenter import tq
tq.initialize(__file__)
clear_ptr = tq.clear_sector(block_code='CSBK')
print(clear_ptr)
```

### 数据样本

```
{
   "Error" : "清空CSBK板块成功",
   "ErrorId" : "0",
   "run_id" : "1"
}
```
