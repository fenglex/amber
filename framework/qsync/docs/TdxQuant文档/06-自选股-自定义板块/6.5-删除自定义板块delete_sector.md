# 6.5 删除自定义板块delete_sector

### 删除通达信客户端中的自定义板块

```
delete_sector(block_code:str = ''):
```

### 输入参数

| 参数 | 是否必选 | 参数类型 | 参数说明 |
| --- | --- | --- | --- |
| block_code | Y | str | 自定义板块简称 |

### 接口使用

```
from tqcenter import tq
tq.initialize(__file__)
delete_ptr = tq.delete_sector(block_code='CSBK')
print(delete_ptr)
```

### 数据样本

```
{
   "Error" : "删除CSBK板块成功",
   "ErrorId" : "0",
   "run_id" : "1"
}
```
